# GM-VoTV

**Garry's Mod → Voices of the Void**  
A small-scale, self-contained cooperative fan project.

## 📡 About the Project

This is not a remaster or a full conversion.  
It's an attempt to adapt the **atmosphere, signals, and base maintenance** from *Voices of the Void* into a **cooperative Garry's Mod** experience.

Played by 2+ people. One player acts as **ASO Personnel** (events, drone control, fine-tuning) (yes this is not an automatic game). The others are **ASO Trainees** – people who perform tasks, fix generators, collect hash codes, and panic.

We don't copy the original mechanics 1:1.  
We build something that *feels right* for a late-night session with friends and a cold cup of tea, yet still inspired of Voices of The Void
